### Styling Customization

#### Colors (portfolio.css or styles.scss)
The project uses CSS custom properties. Update these in `portfolio.css`:
```css
:root {
  --first-color: #4E1116;    /* Primary brand color */
  --black-color: #000;        /* Background color */
  --white-color: #FFF;        /* Text color */
}
```

Or edit the SASS variables in `assets/sass/styles.scss`:
```scss
:root {
  --first-color: #4E1116;
  --black-color: #000;
  --white-color: #FFF;
}
```

#### Fonts
Update in `portfolio.css` or `styles.scss`:
```css
@import url('https://fonts.googleapis.com/css2?family=Poppins:wght@400;700&display=swap');

:root {
  --body-font: 'Poppins', sans-serif;
}
```

#### Working with SASS
If you want to use SASS for styling:

1. **Edit SASS file**: Make changes in `assets/sass/styles.scss`
2. **Compile SASS to CSS**: 
   ```bash
   # Install SASS globally (one time)
   npm install -g sass
   
   # Compile SASS to CSS
   sass assets/sass/styles.scss assets/css/styles.css
   
   # Watch for changes (auto-compile)
   sass --watch assets/sass/styles.scss:assets/css/styles.css
   ```
3. **Update HTML**: Link to the compiled CSS in `index.html`:
   ```html
   <link rel="stylesheet" href="assets/css/styles.css" />
   ```

**Note**: Currently, the project uses `portfolio.css`. You can switch to `styles.css` by updating the link in `index.html`.

### Adding Projects
1. Locate the projects section in `index.html`
2. Duplicate a project card
3. Update content, images, and links
4. Add corresponding images to `assets/img/`

### Updating Resume
1. Replace the PDF in `assets/resume/`
2. Update the link in `index.html`:
   ```html
   <a href="./assets/resume/your-resume.pdf" download>
   ```
